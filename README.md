### 게임개발 실습

보완관

## 웨이브 공격으로 은행을 지키는 게임

1에서 5단계
은행 파괴 혹은 플레이어 사망시 패배
적 리더가 등장하며 쇼다운 매치로 진행, 3초라는 타이머가 끝나고 shoot이라는 글자가 나올시 스페이스를 누르며 더 빨리 누른쪽이 승리(미정)

필요한 이미지 2d

## player기획

조작키 :  wasd(이동) + space(회피)
모션 : 걷기, 구르기(회피)

 무기 :  리볼버

상점 : 무기구매 : 쌍 리봅버, 윈체스터, 롱소드, 샷건
    업그레이드 : 속도, 데미지, 투사체 발사 속도, 연사, 체력, 은행 체력, 은행 공격 시스템

기본 체력 30
기본 속도 3

업그레이드 +=시작1 방식으로 10단계
단 은행 공격근 최대 3단계까지만

데미지 : 리볼버 3, 쌍 리볼버 6, 윈체스터 10, 롱소드 15, 샷건 1발당 3데미지(최대 15)

## enemies 기획

근접 : 칼 , 창
원거리 : 리볼버, 기관총, 윈체스터

데미지 방식 : 칼 5, 창 7, 리볼러 5, 기관총 3, 윈체스터 10

속도 : 원주민 속도 5, 무법자  3, 말을 탄 *적* +4 마차를 탄 무법자 +3

체력 : 원주민 20, 무법자 30, 말을 탄 *적* +5, 마차를 탄 무법자 + 10

적 디자인 : 아메리카 원주민 (근접 칼)
아메리카 원주민 (창)                            -------------> 공격 모션, 사망시 모션, 이동시 모션 필요
말을 탄 아메리카 원주민(창)

무법자 (리볼버)
마차를 탄 무법자(기관총)
말을 탄 무법자(윈체스터)

은행
은행의 체력은 100
공격시스템 시작시 데미지 2로 시작
적금 시스템으로 돈을 넣고 라운드가 자날 시 체력 및 돈이 추가로 획득

필요 이미지

스페셜 공격 키 : 스페이스(미정)
