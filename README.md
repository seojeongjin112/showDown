# 설치 및 실행 안내

이 저장소에는 **Unity Asset Store 에셋 원본이 들어 있지 않습니다.** 에셋은 재배포가 금지되어 있어서 공개 저장소에 올리지 않았습니다. 아래 순서대로 에셋을 직접 받아 임포트하면 게임이 실행됩니다.

## 개발 환경

| 항목 | 버전 |
|---|---|
| Unity | **6000.3.22f1** (Unity 6.3 LTS) |
| 렌더 파이프라인 | URP 17.3.0 |
| 입력 | Input System 1.20.0 (신규 입력 시스템만 사용, 레거시 `Input` 사용 안 함) |
| 대상 플랫폼 | Windows Standalone |

URP와 Input System은 `Packages/manifest.json`에 이미 들어 있어서 따로 설치하지 않아도 됩니다.

## 필요한 에셋 (Unity Asset Store에서 각자 받기)

| 에셋 | 제작사 | 용도 | 설치되어야 하는 폴더 |
|---|---|---|---|
| **Micro Wild West** | Codematik | 지면 타일, 건물·소품 그림 | `Assets/Codematik/MicroWildWest` |
| **2D Infinite Character Forge - Wild West Edition** (1.0.0 RC1) | Lucasoft Arts | 플레이어 캐릭터와 걷기·구르기 등 애니메이션 | `Assets/InfiniteCharacterForgeWildWest` |

- 두 에셋의 라이선스와 사용 범위는 **각 에셋 스토어 페이지의 약관**을 따릅니다. 이 저장소는 에셋 원본을 제공하지 않습니다.
- 에셋 이름으로 Asset Store에서 검색해 받으세요.

## 설치 순서

1. 이 저장소를 clone 합니다.
2. Unity Hub에서 **6000.3.22f1**로 프로젝트를 엽니다. 처음 열 때 패키지 복원과 임포트에 시간이 걸립니다.
3. Unity 에디터에서 **Window > Package Manager > My Assets**를 열어 위 두 에셋을 **Download 후 Import** 합니다.
4. 임포트가 끝나고 컴파일이 끝날 때까지 기다립니다. 콘솔에 빨간 에러가 없으면 준비된 것입니다.
5. `Assets/Scenes/Arena2D.unity`를 열고 **Play**를 누릅니다.

> **폴더 이름과 위치를 바꾸지 마세요.** 씬, 프리팹, 머티리얼이 에셋 안의 파일을 고유 ID로 가리키고 있어서, 폴더를 옮기거나 에셋을 다른 방식으로 복사해 넣으면 연결이 끊어질 수 있습니다. 반드시 Package Manager의 Import로 설치하세요.

## 조작법

| 입력 | 동작 |
|---|---|
| **W A S D** | 이동 (카메라 방향 기준) |
| **Space** | 구르기 (이동 중인 방향으로, 멈춰 있으면 마지막으로 움직인 방향) |
| **마우스 이동** | 카메라 회전 (좌우 360도, 위아래 5~30도) |
| **Esc** | 마우스 커서 잠금 해제 |
| **마우스 왼쪽 클릭** | 커서를 다시 잠그고 카메라 조작 재개 |

화면 **중앙에서 조금 위**에 있는 십자 표시는 조준선입니다.

## 현재 구현 상태

**구현됨**
- 서부영화식 ㄷ자 마을 맵(`Arena2D` 씬): 은행이 북쪽 한가운데, 양옆과 동·서 날개에 건물, 광장 가운데에 우물
- 대부분의 건물은 4면에 그림을 붙인 3D 박스이고(교수대만 평면 그림), 충돌 박스가 모양과 일치하며, **플레이어를 가리면 투명해집니다**
- 플레이어 이동, 걷기·구르기 애니메이션, 구르기 중 무적 플래그(`IsInvulnerable`)
- 마우스로 회전하는 3인칭 카메라, 중앙 조준선
- 스프라이트가 항상 카메라 정면을 보는 빌보드 표현 (2.5D)

**미구현** (위 기획 내용 중 아직 만들지 않은 것)
- 사격과 무기, 적, 웨이브, 상점·업그레이드, 은행 체력, 쇼다운 매치
- `Arena2D`에서는 아직 적과 웨이브가 동작하지 않습니다. 예전 3D 시험 씬(`Arena`)에 있던 적·웨이브 스크립트는 새 플레이어 구조에 맞게 다시 작업해야 합니다.

## 알려진 제한

- **건물 그림이 연결되지 않습니다.** 건물에 붙이는 그림은 Micro Wild West의 건물 그림을 잘라 가공해 만든 이미지라서 저장소에 포함하지 않았고, 이를 자동으로 만들어 주는 도구는 아직 제공되지 않았습니다. 에셋만 설치하면 건물이 **제 위치와 크기의 박스로는 보이지만, 건물 그림 대신 흰색이나 단색 판으로 보일 수 있습니다.**
- 에셋을 설치하지 않으면 지면 타일과 플레이어 캐릭터가 보이지 않고, 콘솔에 Missing Script가 표시됩니다.
- 플레이 시작 직후 카메라가 마우스 이동량 때문에 몇 도 돌아가 있을 수 있습니다.
